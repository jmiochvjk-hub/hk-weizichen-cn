# 魏子宸 · 闪光坐标（网页镜像）

这是对 <https://hk.weizichen.cn/> 可公开访问前端的静态镜像，抓取时间为 2026-08-29（Asia/Shanghai）。

仓库包含：

- 服务端返回的首页 HTML
- Next.js 前端脚本与样式
- 站点同源的图片、音频和地图素材

## 本地预览

请使用 HTTP 服务器从仓库根目录访问；不要直接双击 `index.html`，因为页面资源使用根路径。

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。

## 镜像限制

- 这是公开网页的前端快照，不包含原始 Next.js 项目源码、构建配置、数据库、环境变量或服务器端代码。
- 祝福/留言功能依赖原站 `/api/wishes` 接口；离线或仅通过 GitHub Pages 托管时不可用。
- 部分视频封面仍由原页面引用的第三方平台提供，第三方链接失效时对应内容可能无法显示。
- 页面中的署名、来源链接和版权说明均按抓取时的公开页面保留。

原站制作与运营署名：Vksmxas。本站点镜像不改变原页面中的版权与来源声明。
